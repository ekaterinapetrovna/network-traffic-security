# Мониторинг сетевого трафика предприятия

Практическая работа по дисциплине «Информационная безопасность бизнес-процессов».

**Тема:** Обеспечение безопасности сетевого трафика предприятия.

**Предприятие:** ООО «ТехноПрофи» (учебный пример).

## Цель работы

Разработка и исследование учебной системы мониторинга сетевого трафика для обнаружения потенциальных угроз информационной безопасности.

## Выполненные задания

### Задание 1. Улучшение системы мониторинга

- Реализовано обнаружение потенциальных DDoS-атак по количеству пакетов в секунду.
- Организовано ведение журнала аудита событий безопасности.
- Реализовано формирование уведомлений для Telegram и Slack в демонстрационном режиме.

### Задание 2. Оценка экономической эффективности

- Выполнен расчёт экономии от сокращения простоев и снижения ожидаемых потерь.
- Рассчитан ROI первого года — 123,33%.
- Определён условный срок окупаемости — 4,72 месяца.
- Построен график экономической эффективности.

Расчёты основаны на учебных финансовых допущениях.

### Задание 3. Интеграция системы мониторинга

- Смоделирована биометрическая аутентификация сотрудников.
- Смоделирована обработка событий облачных платформ AWS и Azure.
- Реализована учебная проверка IP-адресов по тестовым индикаторам MISP и OTX.

## Результаты

В ходе моделирования зарегистрировано 7 событий информационной безопасности. События сохранены в журнале аудита формата JSON Lines.

## Основной файл работы

`Кремезная_ОИББП_Лекция_07.ipynb`

Блокнот содержит программный код Python, пояснения, результаты выполнения, таблицы и графики.

## Среда разработки

Google Colab, Python, Pandas, NumPy, Matplotlib.

**Примечание:** мониторинг и интеграции с внешними сервисами реализованы в учебном демонстрационном режиме.
